🚀 Proud to Present Our AI-Powered Drone Detection & Classification System

As part of the AICW – AI Career for Women program, we had the opportunity to design and develop an end-to-end Drone Detection & Classification System, leveraging the power of Artificial Intelligence, Deep Learning, and Computer Vision.

With the increasing adoption of unmanned aerial vehicles (UAVs) across industries, the ability to accurately identify and classify drones has become a critical technological challenge. Our project addresses this challenge by utilizing Transfer Learning with MobileNetV2 to build an efficient and accurate image classification model capable of recognizing multiple drone categories.

🔹 What We Built

• Developed a high-performance drone classification model using MobileNetV2
• Applied data preprocessing, augmentation, training, and performance evaluation techniques
• Designed and deployed an interactive web application using Flask
• Integrated MongoDB for efficient data storage and management
• Created a complete AI pipeline from model development to deployment
• Successfully demonstrated the solution before faculty members and mentors

🛠️ Technology Stack

Python | TensorFlow | Keras | Flask | MongoDB | NumPy | Pandas | Matplotlib | HTML | CSS | JavaScript
